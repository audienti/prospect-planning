# prospect-planning

Choose a grounded next action aligned with an experiment approach.

Agent skill and versioned schemas for an Exo-compatible host. No sending capability.

Install from the Audienti marketplace or copy `skills/prospect-planning` into an agent skills directory.

Host workflow names in the skill describe integration contracts. Installing the skill
does not create those APIs, deploy Exora, schedule jobs or authorize outreach.

Claude Code installation:

```sh
claude plugin install prospect-planning --marketplace audienti/plugins
```

Codex installation (after adding the Audienti marketplace):

```sh
codex plugin add prospect-planning@audienti
```
